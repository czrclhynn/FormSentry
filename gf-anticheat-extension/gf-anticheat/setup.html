A CLEAR START

Set Up FormSentry

Smart Examination Monitoring for Google Forms

Before you begin

FormSentry 1.0.0 supports desktop Chrome 120+. Use the extension ZIP and dashboard address supplied by your teacher or maintainer. The Supabase schema and student API must be deployed before students can start.

The source code does not create a public download or deploy a backend automatically. Obtain formsentry-1.0.0.zip and its SHA256SUMS.txt from your trusted maintainer. No native desktop application, enrollment account, or PowerShell installer is required for students.

Student setup

  1. Download the extension

    Use the package your teacher provides. Compare its SHA-256 checksum with the checksum from the same trusted release source.

  2. Extract the ZIP

    Keep the extracted directory in a permanent location.

  3. Open Chrome’s Extensions page

    Enter chrome://extensions/ in Chrome’s address bar.

  4. Enable Developer Mode

    Use the switch on the Extensions page. If your institution disables this, contact its administrator.

  5. Select Load unpacked

    Choose the extracted folder containing manifest.json directly at its root.

  6. Verify FormSentry is enabled

    Check the name and version. Pin its icon if you want quick access to session status.

  7. Open the examination invitation

    Use the exact link copied by the teacher. It opens Google Forms with a FormSentry invitation in the URL fragment. Opening a plain Google Form without an invitation cannot enroll a new attempt.

  8. Enter your full name and email

    These identify your session for the teacher. They are self-declared, not independently verified. You do not need a FormSentry account.

  9. Review the guidelines and consent

    Read what is monitored and check the consent box. Declining leaves monitoring off.

  10. Select Start Examination

    Allow fullscreen if requested. Confirm the panel says Monitoring. A connection is required to register the attempt; later connection interruptions keep activity in a local retry queue.

  11. Submit the Google Form

    Verify the confirmation shown by Google Forms. FormSentry records submission-route evidence when available, but it cannot independently verify that Google accepted your response.

  12. Finish or stop transparently

    If monitoring remains active, use End monitoring in the popup after submitting. You may also stop from the panel for a technical issue or withdrawal of consent. Stopping does not submit answers. Keep Chrome and the extension running until pending uploads finish.

Teacher setup

  1. Open the FormSentry dashboard

    Use the hosted dashboard address provided by the maintainer, or Teacher dashboard in the extension popup.

  2. Register or sign in

    Create an account with your name, email, and password. Verify your email before signing in. Password recovery is available on the sign-in screen.

  3. Create an examination

    Enter a clear title and the full Google Forms respondent link ending in /viewform. Open shortened forms.gle links first. Editor links are rejected.

  4. Select practical rules

    Choose whether to record departures, request fullscreen, and monitor clipboard actions. Add restricted domains if needed. Record Only collects observations; Warning adds calm reminders without locking the exam or blocking websites.

  5. Activate and share

    Set the exam to Active, save it, then use Copy invitation. Share the resulting Google Forms link with the extension ZIP and these instructions. Keep invitation links within the intended class.

  6. Monitor student sessions

    Students appear after identity, consent, and a successful start. The dashboard refreshes every 20 seconds while visible; the extension normally syncs every 30 seconds. Offline devices may appear stale.

  7. Review individual activity

    Select a student to inspect the session ID, dates, submission status, and timeline. A departure is one record with duration, not several duplicate browser signals. An unfinished departure is uploaded when the student returns or monitoring ends.

  8. Export reports

    Export the displayed activity list or a student’s complete timeline as CSV. The main lists show the latest 1,000 records; session export loads all events for that session.

Teacher Ended takes effect on the extension’s next successful sync. It cannot instantly stop an offline device. Records requiring review are not conclusive evidence of academic dishonesty.

Practice checklist

  1. Use a practice exam and two separate browser profiles/devices. Do not use real student information for testing.
  2. Register and verify two teacher accounts. Confirm each sees only its own exams and sessions.
  3. Open an invitation, enter a test identity, and check that Start stays disabled until fields and consent are valid.
  4. Start once, try again, and refresh: keep one session ID and one start record.
  5. Leave and return once: expect one departure episode with a duration. Repeat quickly: expect a second distinct episode.
  6. Switch to another window and return: record focus loss without naming the application or claiming a confirmed Alt+Tab key press.
  7. Test requested fullscreen, clipboard monitoring, configured domains, and gentle reminders.
  8. Disconnect temporarily, return, and reconnect: pending records should arrive once. Do not uninstall or clear storage while uploads are pending.
  9. Submit the practice form and verify Google’s confirmation separately. Check the session’s detected/unverified submission status.
  10. Stop monitoring and perform ordinary browser actions: no further records or restrictions should be created.
  11. Export a student report and verify identity, event descriptions, categories, timestamps and duration.

Troubleshooting

The examination panel is missing

Ensure FormSentry is enabled, then refresh the Google Form. Use the teacher’s complete invitation link, including its fragment. The examination must be Active. If the form or invitation changed, obtain a new link.

“Examination unavailable” or backend errors

Ask the maintainer to verify the Supabase schema, student-api Edge Function, and project API settings. A public API key alone cannot create tables or deploy the function.

I cannot sign in or recover my password

Verify your email. Check your spam folder and ask the maintainer to check Supabase Auth email delivery and allowed redirect URLs. Recovery must redirect to the configured hosted dashboard, not an extension URL.

Uploads are pending

Activity remains in this Chrome profile and retries on the next heartbeat/alarm. Keep the extension enabled and Chrome open. The popup can export the current session’s local records for the teacher if a session ended before all events were accepted. Do not clear local storage.

Reloading the extension

After updating files, select Reload on chrome://extensions/ and refresh the examination page. Reloading during monitoring interrupts the attempt. Reopening the popup alone does not end monitoring.

Submission is not verified

A Google Forms submission route is evidence of an attempted submission, not proof of receipt. Teachers should compare with their Google Forms responses. This release has no Google Forms response synchronization.

Developer Mode is disabled

Ask your institution’s administrator for an approved distribution method. Do not bypass device policy. Chrome Web Store publication is a separate deployment step.

Privacy & technical limits

FormSentry sends the provided student name/email, consent, session status, timestamps and configured browser observations to the teacher’s Supabase project. It does not read answers, clipboard text, passwords, webcam or microphone data.

Monitoring covers the exam’s Chrome window and focus signals observable by Chrome. It cannot identify desktop applications, inspect other devices, guarantee that a student cannot cheat, or prevent a user disabling an unmanaged extension. An invitation authorizes participation; it is not proof of student identity.

Existing local-only configuration and legacy logs are retained on the original profile, but are not automatically uploaded or treated as authenticated Supabase records. Teachers must recreate their examinations in the authenticated dashboard.
